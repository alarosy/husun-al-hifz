# حصون الحفظ

تطبيق ويب لمتابعة برنامج حفظ القرآن الكريم بطريقة **«الحصون الخمسة»** (سعيد أبو العلا حمزة): الحفظ الجديد، ومراجعة القريب، ومراجعة البعيد، والتحضير (القبلي والليلي والأسبوعي)، والقراءة المستمرة.

مضبوط على رواية قالون عن نافع، مصحف الجماهيرية (602 صفحة)، وكل الإعدادات قابلة للتغيير.

**الرابط:** https://alarosy.github.io/husun-al-hifz/

## ما يقدّمه

- **اليوم:** ورد الحفظ بخط كبير، ومهام اليوم في أربع مجموعات (بعد الفجر، وخلال اليوم، وقبل النوم، ومتابعة) مع الوقت المقدّر لكل منها، وعدّاد للقراءة المستمرة، و«يوم تثبيت» للمراجعة فقط، وملاحظات تُحفظ تلقائيًا.
- **الخريطة والسجل:** ثماني بطاقات إحصاء (منها الأيام المتتالية والهامش)، وخريطة لصفحات المصحف الـ602 يمكن تصحيح أي صفحة منها، وشبكة لأيام البرنامج ملوّنة بنسبة الإنجاز.
- **الإعدادات:** كل معاملات الخطة، والنسخة الاحتياطية، ومحو السجل.
- يعمل **دون اتصال** بعد أول زيارة، ويُثبَّت على الهاتف كتطبيق.

## التثبيت على الهاتف

**Android (Chrome):** افتح الرابط، ثم اضغط القائمة ⋮، واختر «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية».

**iPhone (Safari):** افتح الرابط في Safari، ثم اضغط زر المشاركة (المربع ذو السهم)، واختر «إضافة إلى الشاشة الرئيسية».

بعدها يفتح التطبيق من أيقونته كأي تطبيق آخر، ويعمل دون إنترنت.

## نقل البيانات بين الهاتف والحاسوب

البيانات محفوظة **في متصفح كل جهاز فقط**، ولا تُرسل إلى أي خادم. لنقلها:

1. في الجهاز الذي فيه آخر تقدّم: **الإعدادات ← تنزيل ملف JSON**، أو «مشاركة الملف» على الهاتف، أو «نسخ النص».
2. في الجهاز الآخر: **الإعدادات ← رفع ملف**، أو الصق النص في المربع ثم «استيراد النص».

الاستيراد يستبدل كل بيانات الجهاز. إن كانت النسخة المستوردة أقدم من بيانات الجهاز، يعرض التطبيق تحذيرًا قبل الاستبدال. ويذكّرك التطبيق إن مرّ أكثر من 7 أيام دون تنزيل نسخة احتياطية.

## الخصوصية

هذا المستودع العام لا يحتوي أي بيانات شخصية. الملفات `my-backup.json` و`husun-hifz-*.json` مستبعدة في `.gitignore`.

## للمطوّرين

تطبيق ثابت بلا خادم وبلا خطوة بناء: HTML وCSS وJavaScript (ES modules).

| الملف | الدور |
|---|---|
| `js/engine.js` | منطق الخطة: دوال نقية بلا DOM |
| `js/store.js` | الحفظ في `localStorage` (المفتاح `husun-hifz-v1`)، والاستيراد والتصدير |
| `js/ui.js` | العرض والأحداث |
| `sw.js` | Service worker بطريقة cache-first |
| `tests/engine.test.js` | اختبارات المحرّك |

التشغيل محليًا:

```bash
python -m http.server 8765
```

الاختبارات (Node 20 أو أحدث):

```bash
npm test
```

ملاحظة: الأمر `node --test tests/` يعمل في Node 20 فقط؛ في Node 22 وما بعده مرّر نمطًا: `node --test "tests/*.test.js"`، وهذا ما يفعله `npm test`.

**عند نشر تحديث:** غيّر `VERSION` في `sw.js` حتى يحصل المستخدمون على النسخة الجديدة، وسيظهر لهم إشعار «نسخة جديدة من التطبيق جاهزة».
